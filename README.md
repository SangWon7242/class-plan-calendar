# 달력 수업계획서 만들기

엑셀 회원 정리표를 올리면 반마다 달력형 수업계획서 이미지(PNG)를 자동으로 만들어 주는 정적 웹사이트예요.

- 엑셀 → 반별 묶기(No/이름/수업요일/단계/수업일) → 캔버스로 포스터 그리기
- 제목·수업 시간·하단 문구 수정, 색상 4종, 개별 PNG 저장 / 전체 ZIP 저장
- 모든 처리는 브라우저 안에서만 이뤄지고 파일은 서버로 올라가지 않아요
- 폰트: Pretendard (로컬 포함), 라이브러리: SheetJS, JSZip

## 로컬 실행

```bash
python3 -m http.server 8000
```

`http://localhost:8000` 을 열어요. 빌드 과정은 없어요.

## 엑셀 양식

사이트의 「양식 내려받기」 버튼으로 받을 수 있어요.
첫 줄 제목 `No · 팀 여부 · 이름 · 수업요일 · 단계 · 수업일 · 특이사항`,
수업일은 `11월 3일,10일,17일,24일` 형식이에요.
